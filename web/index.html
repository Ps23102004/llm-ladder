A practical confidence gate

Self-consistency chooses the cheapest credible answer.

Each tier takes several independent samples, normalizes the answers, and selects the majority response. Hit that tier’s confidence threshold and the run ends. Miss it and the same prompt moves up one rung.

01

Sample locally

Ask a small Ollama model the same question a few times instead of assuming one response is reliable.

02

Vote with evidence

Use agreement as a lightweight confidence signal—not a hand-wavy model-size guess.

03

Escalate with intent

Send only ambiguous prompts to slower tiers, then record the path in a local JSONL ledger.
